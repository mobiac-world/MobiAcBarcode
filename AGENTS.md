# [MobiAcBarcode]
# Target of app
This app is the barcode generation part of the MobiAc app and is published under the Apache License 2.0.
It must therefore stay self-contained and must not depend on other MobiAc objects or on
proprietary or customer-specific code.
The app shall be as much as possible use the standard of Business Central Cloud.
Customization shall be offered through Publisher and Subscribers.

## Code Standards
- Code itself: Always in English
- Code Comments: Always in English
- Remain always Business Central Cloud compatible
- Every .al file starts with the Apache-2.0 license header (SPDX-License-Identifier, copyright holder "ECHO Motorgeräte Vertrieb Deutschland GmbH", reference to the MobiAc project, reference to LICENSE)

## Documentation
- Generate .md-files in documentation folder always in English except the user instructed it otherwise explicitly
